# 🛍️ Ecommerce Store

A full-stack eCommerce web application built with React, Node.js, Express, and MongoDB.  
This project includes a modern frontend storefront and a backend API for managing products, users, and authentication.

## ✨ Features

- 🛒 Product browsing and listing
- 🔐 User authentication and authorization
- 🧾 Order and cart handling
- 🖥️ Responsive frontend UI
- ⚙️ REST API backend
- 🐳 Docker support for local development
- 📦 MongoDB database integration

## 🏗️ Tech Stack

### Frontend
- React
- React Router
- Redux
- Axios
- SCSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Joi validation

### DevOps / Tools
- Docker
- Docker Compose
- GitHub Actions CI
